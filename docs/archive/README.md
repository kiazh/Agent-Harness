current documentation — live guides live one level up in `docs/` and at
the repository root (`README.md`, `OPERATIONS.md`, `SECURITY.md`,
`CHANGELOG.md`, `FEATURE_LEDGER.md`).

  work cycles (MCP connectors, OAuth, TUI overhaul, production completion,
  persona/RSI, shell/context limits, handoff notes).

  overhaul review (motion GIF, reference PNG).
- [`DEBUGGING_REPORT.md`](DEBUGGING_REPORT.md) — dated debugging snapshot;
