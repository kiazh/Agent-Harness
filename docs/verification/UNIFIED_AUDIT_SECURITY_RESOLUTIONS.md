# Unified audit security and installer resolutions

Source changes for F-09, F-11, F-21, F-22, F-24, F-26, F-27, F-28. No application imports, tests, runtime probes, network calls, database operations, or installer execution were performed. These are source-level resolutions, not executed-platform/security certification.

| Finding | Changed paths and invariant |
| --- | --- |
| F-09 | `machina/tools/file.py`: atomic temporary-file mode preservation uses descriptor chmod where available and pathname chmod otherwise, before replacement. Failure still leaves the original intact. Native Windows ACL and rename behavior remain unverified. |
| F-11 | `machina/tools/file.py`: glob matching now walks context-managed `os.scandir` iterators with a global 4096 inspected-entry budget and 200 result budget, avoiding pathlib's internally eager directory listing. Traversal skips symlinks and matches ordinary components and recursive `**`, including root and directory-only terminal `**` semantics. The registry decorator remains attached to the public async list_files tool. `machina/permissions/policy.py`: recursive-copy inspection materializes at most remaining-budget-plus-one scandir entries, retaining the protected/fail-closed overflow verdict. OS filesystem latency itself is not bounded. No full-mode grant policy changed. |
| F-21 | `machina/security/env_file.py`: reading shares python-dotenv syntax with runtime, including exported/quoted assignments, and updating/removing uses whole parser bindings so multiline values are not left behind. `tools/install-helpers.sh`: reads use python-dotenv with runtime-compatible interpolation and environment precedence; updates parse whole bindings, remove all matching assignments, and emit quoted escaped values. `install.sh`: read failures abort before treating a value as absent. Installer calls use the already-installed `VENV_PY`; standalone helper consumers need Python and python-dotenv. `read_env_values` deliberately returns raw parsed values for assignment presence, removal, and template-preserving edits; effective installer reads use `DotEnv(..., override=False, interpolate=True)` plus the process environment. Secret values reach the quoting subprocess through stdin, not argv. |
| F-22 | `tools/install-helpers.sh`: failed filtering/parsing/writing returns nonzero before replacement; a legitimate empty selection succeeds. Original configuration survives failure. Reads/default detection propagate failures instead of provisioning from a false absent value. No fault injection was run. |
| F-24 | `machina/security/secrets.py`: the POSIX no-follow descriptor open includes `O_NONBLOCK`, so FIFO open cannot wait for a writer before regular-file fstat validation. Alternate Windows pathname validation retains its existing race limitations; no native platform claims. |
| F-26 | `machina/security/secrets.py`: invalidation increments a generation under the cache lock; backend work captures that generation and publishes only if unchanged, using completion time for TTL. An already-running reader may return its fetched value; it cannot refill the cache after invalidation. |
| F-27 | `machina/gateway/features/secrets.py`: mutation responses and catalog report effectiveSet, effectiveSource, effectiveUpdated, and mismatch/unresolved messages from actual config/secret resolution. Resolution errors are reported as unknown, without disclosing values. Stronger operator aliases, mounted files, external backends and session overrides retain precedence. `ui/src/features/keys.ts`: both command and menu mutations display effective-state messages; catalog rows show effective status/source. Legacy responses retain existing rendering. Effective resolution can contact the configured backend when its cache is empty; this was not exercised. |
| F-28 | `machina/permissions/store.py`: pending/approved lookup predicates and atomic durable/memory claims include the requesting agent. Optional omitted actor parameters remain callable but fail closed rather than authorize an unbound actor. `machina/permissions/broker.py`: all five claim sites and pending/approved lookup callers supply req.agent_id. Explicit HTTP resume retains its existing full proposal/session/actor validation. SQL worker races and live DB behavior remain unexecuted. |

Final integration additionally handles quoted dotenv keys with the parser identity, moves effective credential resolution off the event loop, and centralizes its UI protocol fields. File listing uses native path components/case matching and discloses its scan cap.

Static validation: Python `ast.parse` for the seven changed Python modules, `bash -n` for both installer shell files, and `git diff --check`. No TypeScript compiler or behavioral test was run. Bounded glob traversal order is filesystem order before sorting the selected output; large/recursive searches may return a bounded subset. F-30 documentation/policy resolution belongs to the coordinating change.
