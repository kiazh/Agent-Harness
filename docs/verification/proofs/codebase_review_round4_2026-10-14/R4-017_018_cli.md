## R4-017 — Ctrl+C must cancel a running `machina chat` turn

**Root cause (probe-confirmed).** `_run` submitted `asyncio.run(coro)` to a
`ThreadPoolExecutor(max_workers=1)` and blocked the main thread in
`Future.result()`. SIGINT raises `KeyboardInterrupt` in `.result()`, but the
`with ThreadPoolExecutor` block's `__exit__` then calls `shutdown(wait=True)`,
re-blocking the main thread until the worker finished the whole turn — the
running turn is never cancelled (agent keeps calling tools/spending tokens).

**Fix.** `_run` runs `asyncio.run(coro)` directly when the calling thread has no
running loop (the normal CLI case). On the main thread Python 3.11+ `asyncio.Runner`
installs the first-SIGINT handler: Ctrl+C cancels the main task, `_chat`'s existing
`finally` paths run (turn claim release, provider close, DB close), and the interrupt
surfaces after them as `KeyboardInterrupt`. `chat` maps that to `typer.Exit(130)`.
Callers already inside a running event loop keep the previous worker-thread
isolation; non-main threads (where asyncio cannot install signal handlers) run
the loop on their own thread.

**RED — E2E against the unfixed CLI** (`R4-017_018_red_pytest.txt`):
the CLI kept running after SIGINT (10 s bounded wait, then killed):

```
subprocess.TimeoutExpired: Command '[... '-m', 'machina', 'chat', 'go', ...]' timed out after 10.0 seconds
...
pytest.fail("machina chat kept running after SIGINT (deferred interrupt; ...")
```

**RED — stdlib-shape probe** (`R4-017_stdlib_probe.py`, 3 s coroutine + SIGINT at 0.5 s):


## R4-018 — headless `full` mode must activate the session grant

**Root cause.** `chat` created the session with `execution_mode='full'` (the
saved/`--mode full` default) but never saved the session-scoped full grant;
`permissions/policy.decide` returns `pending` for every governed action in full
mode without a live full grant, and the headless transport has no approver →
`needs_approval` → exit 3.

**Fix.** After `session_manager.create` (new-session path only — gateway/REST
parity), call the exact gateway function
`machina.gateway.features.mode.grant_full_default(session)` (deferred import, as
in `gateway/server.py:559-565` and `api/routes/sessions.py:102-108`) and print
one notice when it activates:
`FULL HOST mode active for this session (saved full default).`
Grant-write failures are recorded (`record_failure("cli.chat.grant_full_default",
…)` + `logger.warning`), and the turn proceeds fail-closed (exit 3, never an
un-granted execution).

**RED — E2E against the unfixed CLI** (`R4-017_018_red_pytest.txt`), exit 3:

```
→ read_file
{... "event": "permission_pending", ..., "mode": "full",
 "reason": "full mode requires explicit session activation (/mode full)"}
← Needs approval (...)  Waiting for approval.
✗ Turn paused for approval; it did not run to completion.
assert 3 == 0
```

**GREEN — E2E** (`R4-017_018_green_pytest.txt`) and probe:

```
R4-018: exit=0; provider_requests=3; tool_result_reached_provider=True; grant_notice=True; paused=False
```

Assertions proven by `test_headless_full_mode_runs_routine_tool_without_pause`:
exit 0 under `MACHINA_EXECUTION_MODE=full`, the routine `read_file` tool executed
(tool result reached the provider and its content is printed), zero approval
pauses, and the activation notice is present. (The third provider request in the
probe is the post-turn non-streaming consolidation call the CLI drains before
close; the E2E asserts `>= 2` and `saw_tool_result`.)

## Residual risks / limits

- Ctrl+C on the other CLI subcommands now cancels their coroutine promptly too,
  but Click still reports `Aborted!`/exit 1 there (unchanged status; `chat` alone
  maps to 130).
- A second Ctrl+C during cleanup is delivered immediately by `asyncio.Runner`
  (stdlib behavior); claim release can be cut short in that window — the durable
  claim TTL/expiry still recovers it.
- R4-018 covers the create path (exact gateway parity). A pre-existing CLI session
  created before this fix with `execution_mode='full'` and no grant still pauses;
  resume/approve it or start a new session.
- The E2E SIGINT test needs `MACHINA_TEST_DATABASE_URL` (CI provides it); the
  stdlib-shape probe and the in-process `_run` contract test cover the mechanism
  without a DB.
