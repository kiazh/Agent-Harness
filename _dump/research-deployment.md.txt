1|# Production Deployment Research — AgentHarness
2|
3|> Research into production deployment patterns for a self-hosted AI agent framework.
4|> Covers Docker, Kubernetes, CI/CD, monitoring, observability, logging, secrets, and backup.
5|
6|---
7|
8|## 1. Current State Assessment
9|
10|AgentHarness is a Python 3.11+ async framework with:
11|
12|| Component | Technology | Notes |
13||-----------|-----------|-------|
14|| CLI | Typer + Rich | `ah` command, `asyncio.run()` per invocation |
15|| Database | PostgreSQL + pgvector | asyncpg pool (2-10 connections), 15+ tables |
16|| LLM Provider | OpenRouter / Ollama | httpx async clients, token-bucket rate limiting |
17|| Context Store | MessagePack in BYTEA | `context_chunks` with HNSW embedding index |
18|| Skills | File-based registry | YAML frontmatter, loaded from `skills/` |
19|| Tools | In-process registry | `ah/tools/builtins.py` |
20|| CI | GitHub Actions | ruff + pytest, no CD pipeline |
21|| Config | Environment variables | `DATABASE_URL`, `OPENROUTER_API_KEY` |
22|
23|**Key deployment characteristics:**
24|- **Stateless compute** — agent runs are ephemeral; all state lives in PostgreSQL
25|- **Single-process compute with two entry points** — the one-shot CLI (`ah chat`), a long-running gateway (`python -m ah.gateway`) driven by the UI, and the HTTP API server (`ah serve`) are available today
26|- **External LLM dependency** — OpenRouter API or local Ollama
27|- **pgvector required** — `CREATE EXTENSION vector` in schema.sql

31|## 2. Docker
32|
33|### 2.1 Container Strategy
34|
35|AgentHarness has two natural container boundaries:
36|
37|1. **AgentHarness CLI image** — the `ah` binary + Python runtime
38|2. **PostgreSQL + pgvector image** — the stateful data layer
39|
40|A `docker-compose.yml` for local development and single-node production:
41|
42|```yaml
43|# docker-compose.yml
44|services:
45|  postgres:
46|    image: pgvector/pgvector:pg16
47|    environment:
48|      POSTGRES_DB: agentharness
49|      POSTGRES_USER: ${POSTGRES_USER:-ah}
50|      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:?required}
51|    volumes:
52|      - pgdata:/var/lib/postgresql/data
53|      - ./backups:/backups
54|    ports:
55|      - "5432:5432"
56|    healthcheck:
57|      test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER:-ah} -d agentharness"]
58|      interval: 5s
59|      timeout: 3s
60|      retries: 10
61|    restart: unless-stopped
62|
63|  agentharness:
64|    build:
65|      context: .
66|      dockerfile: Dockerfile
67|    environment:
68|      DATABASE_URL: postgresql://${POSTGRES_USER:***@postgres:5432/agentharness
69|      OPENROUTER_API_KEY: ${OPENROUTER_API_KEY}
70|      LLM_RATE_LIMIT_CALLS_PER_MINUTE: ${LLM_RATE_LIMIT:-10}
71|    depends_on:
72|      postgres:
73|        condition: service_healthy
74|    # For interactive CLI use:
75|    #   docker compose run --rm agentharness ah chat "hello"
76|    # For a long-running API server (future):
77|    #   command: ["ah", "serve", "--host", "0.0.0.0", "--port", "8000"]
78|    restart: unless-stopped
79|
80|volumes:
81|  pgdata:
82|```

84|### 2.2 Dockerfile
85|
86|```dockerfile
87|# Dockerfile
88|FROM python:3.11-slim AS base
89|
90|# Security: run as non-root
91|RUN groupadd -r ah && useradd -r -g ah ah
92|
93|WORKDIR /app
94|
95|# Install dependencies first (layer caching)
96|COPY pyproject.toml README.md ./
97|RUN pip install --no-cache-dir .
98|
99|# Copy application code
100|COPY ah/ ./ah/
101|COPY skills/ ./skills/
102|
103|# Initialize schema on first run (entrypoint handles this)
104|COPY docker-entrypoint.sh /usr/local/bin/
105|RUN chmod +x /usr/local/bin/docker-entrypoint.sh
106|
107|USER ah
108|ENTRYPOINT ["docker-entrypoint.sh"]
109|CMD ["ah", "--help"]
110|```

112|### 2.3 Entrypoint Pattern
113|
114|```bash
115|#!/usr/bin/env bash
116|# docker-entrypoint.sh
117|set -euo pipefail
118|
119|# Wait for PostgreSQL
120|until pg_isready -h "${DATABASE_URL#*@}" -p 5432; do
121|  echo "Waiting for PostgreSQL..."
122|  sleep 1
123|done
124|
125|# Initialize schema (idempotent)
126|ah init
127|
128|# Run the actual command
129|exec "$@"
130|```

132|### 2.4 Multi-Stage Build (Production)
133|
134|```dockerfile
135|# Dockerfile.prod — smaller attack surface
136|FROM python:3.11-slim AS builder
137|WORKDIR /build
138|COPY pyproject.toml .
139|RUN pip install --no-cache-dir --prefix=/install .
140|
141|FROM python:3.11-slim
142|COPY --from=builder /install /usr/local
143|COPY ah/ /app/ah/
144|COPY skills/ /app/skills/
145|WORKDIR /app
146|RUN groupadd -r ah && useradd -r -g ah ah && chown -R ah:ah /app
147|USER ah
148|ENTRYPOINT ["ah"]
149|```
150|
151|### 2.5 Key Docker Decisions
152|
153|| Decision | Rationale |
154||----------|-----------|
155|| `pgvector/pgvector:pg16` base image | Official pgvector builds; avoids manual compilation |
156|| Non-root user | Security best practice; container escape mitigation |
157|| `depends_on: service_healthy` | Prevents race condition on first boot |
158|| Named volume for PGDATA | Survives container recreation |
159|| Multi-stage build | ~50% smaller final image, no build tools in prod |
160|| `pip install .` not `pip install -e .` | Production needs installed package, not editable |

405|
406|### 4.1 Current State
407|
408|The project has two GitHub Actions workflows:
409|- `ci.yml` — runs on push to main + PRs: ruff check, ruff format, pytest
410|- `pr.yml` — same checks on PRs

609|### 5.1 Metrics to Expose
610|
611|AgentHarness should expose Prometheus metrics. Key metrics for an AI agent framework:
612|
613|| Category | Metric | Type | Description |
614||----------|--------|------|-------------|
615|| **LLM** | `ah_llm_requests_total` | Counter | Total LLM API calls by provider/model |
616|| **LLM** | `ah_llm_tokens_total` | Counter | Total tokens consumed (prompt + completion) |
617|| **LLM** | `ah_llm_latency_seconds` | Histogram | LLM call latency |
618|| **LLM** | `ah_llm_errors_total` | Counter | LLM call failures by error type |
619|| **Agent** | `ah_agent_runs_total` | Counter | Total agent runs |
620|| **Agent** | `ah_agent_iterations` | Histogram | Iterations per run |
621|| **Agent** | `ah_agent_duration_seconds` | Histogram | End-to-end run duration |
622|| **Agent** | `ah_agent_token_budget_exceeded` | Counter | Runs that hit token budget |
623|| **Tools** | `ah_tool_calls_total` | Counter | Tool invocations by tool name |
624|| **Tools** | `ah_tool_duration_seconds` | Histogram | Tool execution time |
625|| **Tools** | `ah_tool_errors_total` | Counter | Tool execution failures |
626|| **DB** | `ah_db_pool_connections` | Gauge | Current pool size / available |
627|| **DB** | `ah_db_query_duration_seconds` | Histogram | Query latency |
628|| **Sessions** | `ah_active_sessions` | Gauge | Currently active sessions |

632|### 5.2 Prometheus Instrumentation
633|
634|```python
635|# ah/observability/metrics.py
636|from prometheus_client import Counter, Histogram, Gauge, Info, generate_latest
637|from functools import wraps
638|import time
639|
640|# LLM metrics
641|LLM_REQUESTS = Counter(
642|    "ah_llm_requests_total",
643|    "Total LLM API calls",
644|    ["provider", "model"],
645|)
646|LLM_TOKENS = Counter(
647|    "ah_llm_tokens_total",
648|    "Total tokens consumed",
649|    ["provider", "model", "type"],  # type: prompt | completion
650|)
651|LLM_LATENCY = Histogram(
652|    "ah_llm_latency_seconds",
653|    "LLM call latency",
654|    ["provider", "model"],
655|    buckets=[0.1, 0.5, 1.0, 2.0, 5.0, 10.0, 30.0, 60.0, 120.0],
656|)
657|LLM_ERRORS = Counter(
658|    "ah_llm_errors_total",
659|    "LLM call failures",
660|    ["provider", "model", "error_type"],
661|)
662|
663|# Agent metrics
664|AGENT_RUNS = Counter("ah_agent_runs_total", "Total agent runs", ["agent_id"])
665|AGENT_ITERATIONS = Histogram("ah_agent_iterations", "Iterations per run", ["agent_id"])
666|AGENT_DURATION = Histogram("ah_agent_duration_seconds", "Agent run duration", ["agent_id"])
667|AGENT_BUDGET_EXCEEDED = Counter("ah_agent_token_budget_exceeded", "Token budget exceeded")
668|
669|# Tool metrics
670|TOOL_CALLS = Counter("ah_tool_calls_total", "Tool invocations", ["tool_name"])
671|TOOL_DURATION = Histogram("ah_tool_duration_seconds", "Tool execution time", ["tool_name"])
672|TOOL_ERRORS = Counter("ah_tool_errors_total", "Tool failures", ["tool_name"])
673|
674|# DB metrics
675|DB_POOL_SIZE = Gauge("ah_db_pool_connections", "DB pool connections", ["state"])
676|DB_QUERY_DURATION = Histogram("ah_db_query_duration_seconds", "DB query latency")
677|
678|# Session metrics
679|ACTIVE_SESSIONS = Gauge("ah_active_sessions", "Currently active sessions")
680|CONTEXT_CHUNKS = Counter("ah_context_chunks_total", "Context chunks stored", ["chunk_type"])
681|
682|# App info
683|APP_INFO = Info("agentharness", "AgentHarness application info")
684|
685|
686|def track_llm_call(provider: str, model: str):
687|    """Context manager to track an LLM call."""
688|    LLM_REQUESTS.labels(provider=provider, model=model).inc()
689|    start = time.monotonic()
690|    try:
691|        yield
692|    except Exception as e:
693|        LLM_ERRORS.labels(provider=provider, model=model, error_type=type(e).__name__).inc()
694|        raise
695|    finally:
696|        LLM_LATENCY.labels(provider=provider, model=model).observe(time.monotonic() - start)
697|
698|
699|def track_tool_call(tool_name: str):
700|    """Context manager to track a tool execution."""
701|    TOOL_CALLS.labels(tool_name=tool_name).inc()
702|    start = time.monotonic()
703|    try:
704|        yield
705|    except Exception:
706|        TOOL_ERRORS.labels(tool_name=tool_name).inc()
707|        raise
708|    finally:
709|        TOOL_DURATION.labels(tool_name=tool_name).observe(time.monotonic() - start)
710|```

938|
939|```python
940|# ah/observability/logging.py
941|import logging
942|import json
943|import sys
944|import uuid
945|from datetime import datetime, timezone
946|from contextvars import ContextVar
947|
948|# Context variable for request/session correlation
949|request_id_var: ContextVar[str] = ContextVar("request_id", default="")
950|session_id_var: ContextVar[str] = ContextVar("session_id", default="")

952|
953|class StructuredLogFormatter(logging.Formatter):
954|    """JSON formatter with correlation IDs."""
955|
956|    def format(self, record: logging.LogRecord) -> str:
957|        log_entry = {
958|            "timestamp": datetime.now(timezone.utc).isoformat(),
959|            "level": record.levelname,
960|            "logger": record.name,
961|            "message": record.getMessage(),
962|            "request_id": request_id_var.get(),

968|            },
969|        }
970|        if record.exc_info:
971|            log_entry["exception"] = self.formatException(record.exc_info)
972|        return json.dumps(log_entry, default=str)

975|def setup_logging(level: str = "INFO"):

1124|
1125|### 8.1 Current State
1126|
1127|AgentHarness reads secrets from environment variables (`DATABASE_URL`, `OPENROUTER_API_KEY`) loaded via `python-dotenv`, with `*_FILE` mounted-secret support and optional HashiCorp Vault or AWS Secrets Manager backends (`AGENT_HARNESS_SECRET_BACKEND`). Environment variables are still the default; the external backends cover production secret rotation.

1130|

1133|| `DATABASE_URL` | PostgreSQL credentials | 90 days |

1178|

1221|### 9.2 PostgreSQL Backup Strategy
1222|
1223|```bash
1224|#!/usr/bin/env bash
1225|# scripts/backup.sh — run via cron or Kubernetes CronJob
1226|
1227|set -euo pipefail
1228|
1229|BACKUP_DIR="/backups"
1230|TIMESTAMP=$(date +%Y%m%d_%H%M%S)
1231|RETENTION_DAYS=30
1232|S3_BUCKET="s3://agentharness-backups"
1233|
1234|# Full backup with pg_dump
1235|pg_dump "$DATABASE_URL" \
1236|    --format=custom \
1237|    --compress=9 \
1238|    --file="${BACKUP_DIR}/agentharness_${TIMESTAMP}.dump"
1239|
1240|# Verify backup
1241|pg_restore --list "${BACKUP_DIR}/agentharness_${TIMESTAMP}.dump" > /dev/null
1242|
1243|# Upload to S3
1244|aws s3 cp "${BACKUP_DIR}/agentharness_${TIMESTAMP}.dump" "${S3_BUCKET}/daily/"
1245|
1246|# Clean old local backups
1247|find "${BACKUP_DIR}" -name "*.dump" -mtime +${RETENTION_DAYS} -delete
1248|
1249|# Clean old S3 backups (lifecycle policy also handles this)
1250|aws s3 ls "${S3_BUCKET}/daily/" | \
1251|    awk -v date="$(date -d "${RETENTION_DAYS} days ago" +%Y%m%d)" \
1252|    '$1 < date {print $4}' | \
1253|    xargs -I {} aws s3 rm "${S3_BUCKET}/daily/{}"
1254|
1255|echo "Backup completed: agentharness_${TIMESTAMP}.dump"
1256|```

1334|psql "$TEMP_DB" -c "SELECT COUNT(*) FROM sessions;" > /dev/null
1335|psql "$TEMP_DB" -c "SELECT COUNT(*) FROM context_chunks;" > /dev/null
1336|psql "$TEMP_DB" -c "SELECT pg_size_pretty(pg_database_size('${TEMP_DB}'));"
1337|
1338|# Cleanup
1339|dropdb "$TEMP_DB"
1340|rm /tmp/verify.dump
1341|
1342|echo "Backup verification passed: ${LATEST_BACKUP}"
